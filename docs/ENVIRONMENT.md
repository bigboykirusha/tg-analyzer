# Переменные окружения

Локально всё читается из корневого `.env` (шаблон — `.env.example`). На сервере значения лежат в `deploy/.env` (шаблон — `deploy/.env.example`, как они попадают в сервисы — `deploy/docker-compose.yml`); API и worker используют одинаковые серверные переменные.

## API и worker

| Переменная                                               | Обязательна           | Назначение                                                                                                                                                                                                            |
| -------------------------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                                           | да                    | PostgreSQL.                                                                                                                                                                                                           |
| `REDIS_URL`                                              | да                    | Redis (очереди, лимиты, прогресс). Политика памяти — `noeviction`.                                                                                                                                                    |
| `SESSION_ENCRYPTION_KEY`                                 | да                    | 64 hex-символа (`openssl rand -hex 32`), шифрует Telegram-сессии.                                                                                                                                                     |
| `JWT_SECRET`, `JWT_REFRESH_SECRET`                       | да                    | Разные случайные строки ≥ 32 символов.                                                                                                                                                                                |
| `TELEGRAM_MODE`                                          | нет (`live`)          | `fake` — демо-аккаунт без Telegram; в production запрещён.                                                                                                                                                            |
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`                   | при `live`            | Ключи приложения с my.telegram.org.                                                                                                                                                                                   |
| `CORS_ORIGIN`                                            | да                    | Точные origin веб-клиента через запятую; в production только `https`.                                                                                                                                                 |
| `COOKIE_SECURE`                                          | нет                   | По умолчанию `true` в production.                                                                                                                                                                                     |
| `COOKIE_SAME_SITE`                                       | нет (`lax`)           | `none` требует `COOKIE_SECURE=true`.                                                                                                                                                                                  |
| `COOKIE_DOMAIN`                                          | нет                   | Обычно не задаётся: cookie остаётся host-only.                                                                                                                                                                        |
| `API_HOST`, `API_PORT` / `PORT`                          | нет                   | Адрес и порт API; платформы обычно задают `PORT`.                                                                                                                                                                     |
| `LOG_LEVEL`                                              | нет (`info`)          | Уровень логов pino.                                                                                                                                                                                                   |
| `AUTH_RATE_LIMIT_MAX`, `AUTH_RATE_LIMIT_WINDOW`          | нет (`5`, `1 minute`) | Лимит попыток входа.                                                                                                                                                                                                  |
| `CHAT_REPARSE_COOLDOWN_MINUTES`                          | нет (`60`)            | Пауза перед повторным анализом того же чата.                                                                                                                                                                          |
| `DATA_RETENTION_DAYS`                                    | нет (`365`)           | Сколько хранить историю запусков.                                                                                                                                                                                     |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`            | нет                   | Свой бот: новости подписчикам и «Сообщить о проблеме» (@BotFather). Без токена бот выключен.                                                                                                                          |
| `FREE_ANALYSES_PER_DAY`                                  | нет                   | Бесплатный лимит: анализов на человека за 24 часа, по умолчанию 5. `0` — без лимита.                                                                                                                                  |
| `APP_URL`                                                | нет                   | Адрес сайта для кнопок в сообщениях бота; иначе первый `CORS_ORIGIN`.                                                                                                                                                 |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | нет                   | Web push («Отчёт готов» и другие события человека): пара ключей (`npx web-push generate-vapid-keys`) и контакт `mailto:` или https. Без всех трёх пуш выключен. Ключи не меняют: старые подписки перестанут работать. |
| `ALERT_WEBHOOK_URL`                                      | нет                   | Адрес входящего webhook (Slack, Mattermost, Discord и т. п.): API шлёт туда JSON с полями `text` и `content`. Без него и без Telegram-пары алерты выключены.                                                          |
| `ALERT_TELEGRAM_BOT_TOKEN`, `ALERT_TELEGRAM_CHAT_ID`     | нет                   | Альтернатива webhook: сообщение в Telegram-чат от бота (можно завести отдельного, не того, что шлёт «Отчёт готов»). Нужны обе.                                                                                        |
| `ALERT_ERROR_THRESHOLD`, `ALERT_WINDOW_MINUTES`          | нет (`20`, `5`)       | Всплеск: столько ошибок одного вида (5xx API, ошибки браузера, ошибки worker) за окно в минутах.                                                                                                                      |
| `ALERT_THROTTLE_MINUTES`                                 | нет (`30`)            | Один и тот же алерт уходит не чаще, чем раз в столько минут (счётчик общий в Redis).                                                                                                                                  |

В production API отказывается стартовать с `TELEGRAM_MODE=fake`, http-origin в `CORS_ORIGIN`, выключенным `COOKIE_SECURE` или секретами-заглушками.

## Web

| Переменная                | Когда читается | Назначение                                                                                                 |
| ------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------- |
| `NUXT_API_PROXY_TARGET`   | runtime        | Адрес API, на который web-сервер проксирует `/api/*`.                                                      |
| `NUXT_PUBLIC_WS_URL`      | build          | Прямой `wss://` адрес API для прогресса. Попадает в CSP, поэтому задаётся при сборке.                      |
| `NUXT_PUBLIC_SITE_URL`    | build          | Канонический адрес сайта (SEO).                                                                            |
| `NUXT_PUBLIC_CHANNEL_URL` | runtime        | Ссылка «Канал» в подвале (Telegram-канал). Пусто — ссылки нет. На сервере — `CHANNEL_URL` в `deploy/.env`. |
| `NUXT_PUBLIC_SUPPORT_URL` | runtime        | Ссылка «Поддержать» в подвале (страница доната). Пусто — ссылки нет. На сервере — `SUPPORT_URL`.           |

Переменные `NUXT_PUBLIC_*` видны в браузере — секретов в них быть не должно.
