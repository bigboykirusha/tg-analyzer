# UX-ревизия: промт и план

Этот файл — задание, по которому прошёл дизайн-проход. Его можно переиспользовать для следующих итераций.

## Промт

> Ты — продуктовый дизайнер и фронтенд-разработчик TG Analyzer (Nuxt 4, свои UI-компоненты, токены в `tokens.css`).
> Цель: приложение должно быть понятным с первого экрана, одинаково аккуратным на телефоне и десктопе и выглядеть как одна система, а не набор экранов.
>
> 1. **Концепция.** Продукт — «зеркало ваших переписок». Главный объект — _отчёт по чату_. Главная страница
>    отвечает на два вопроса: «что я уже узнал» (готовые отчёты) и «что ещё можно разобрать» (чаты). Новичок
>    видит, что произойдёт после нажатия «Анализ» и что тексты не сохраняются.
> 2. **Согласованность смысла.** Одна и та же метрика не может давать два разных ответа на одном экране
>    (пик-час в KPI против «обычно на связи» в разделе). Числа в KPI — те же, что в разделах.
> 3. **Навигация.** Отчёт длинный: у разделов должна быть всегда доступная навигация; на телефоне — липкая
>    полоса разделов со скролл-спаем вместо бесконечной ленты без ориентиров.
> 4. **Единый дизайн.** Шапка выровнена по той же сетке, что и контент. Нет «карточки в карточке». Один стиль
>    заголовка секции (заголовок + пояснение, без дублирующих надзаголовков). Числа — табличные цифры основного
>    шрифта, а не моноширинный шрифт с разъехавшимися разрядами. Акцентная (primary) кнопка — одна на экран.
> 5. **Адаптив.** Ни одной страницы с горизонтальным скроллом на 360–430 px. Подписи осей не налезают друг на друга.
>    Плотные графики (по дням за год) агрегируются до недель.
> 6. **Не ломать.** Тексты — через i18n (ru + en), тесты/линт/typecheck зелёные, e2e-селекторы сохраняются.

## Найдено при аудите

| Где            | Проблема                                                                    | Решение                                                           |
| -------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Главная        | 12 одинаковых синих кнопок «Анализ», готовые отчёты теряются в общем списке | Блок «Ваши отчёты» сверху карточками, кнопки «Анализ» — спокойные |
| Главная        | Нет объяснения для нового пользователя                                      | Вводный блок «Как это работает» пока нет ни одного отчёта         |
| Главная        | Не видно, личный это чат или группа                                         | Иконка типа и фильтр «Личные / Группы»                            |
| Главная        | Карточка-стекло, внутри ещё рамка списка                                    | Один уровень поверхности                                          |
| Шапка          | Логотип у края экрана, контент по центру узкой колонкой                     | Шапка и страницы в одном контейнере                               |
| Отчёт          | KPI «Пик активности 01:00» противоречит «Обычно 20:00–23:00»                | KPI показывает то же окно, что и раздел                           |
| Отчёт          | Числа моноширинным шрифтом: «1 662»                                         | Табличные цифры основного шрифта                                  |
| Отчёт          | Надзаголовок дублирует заголовок («БАЛАНС / Отправлено и получено»)         | Только заголовок и пояснение                                      |
| Отчёт, телефон | Лента 6–9 тысяч px без навигации                                            | Липкая полоса разделов со скролл-спаем                            |
| Отчёт          | График «по дням» за год — шум                                               | Неделями, если период длиннее ~4 месяцев                          |
| Отчёт, телефон | Подписи часов слипаются («12:0015:0018:00»)                                 | Реже подписи на узких экранах                                     |
| Вход, телефон  | Страница шире экрана (409 px при 390)                                       | Исправлен грид                                                    |
| Запуск         | `.env.example` с пустыми `TELEGRAM_API_ID=` не стартует даже в fake-режиме  | Пустые строки считаются «не задано»                               |
