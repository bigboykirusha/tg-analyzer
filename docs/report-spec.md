## 1. Принципы

1. **Один факт — один дом.** Каждая величина показывается в одной карточке. Исключение одно: «Чем выделяется этот чат» — анонс, он повторяет факт и ведёт по якорю туда, где факт живёт.
2. **Карточка — вопрос → ответ → картинка.** Заголовок задаёт вопрос, ответ отвечает одной фразой, картинка показывает, почему. Никаких вердиктов внизу и пересказа картинки текстом.
3. **Цифры сторон живут в картинке**, а не в подписи внизу. Подписи рядов («Вы», «Мила») и значения стоят прямо у полосок, квадратов и дорожек. **[новое]** Строка `sides` («Вы · 12 Мила · 9» под линией) уходит из всех карточек — владельцу она не нравится, и она дублирует картинку. **[решить]**
4. **Вы — всегда первым, слева, ink.** Собеседник — справа (или вторым рядом), лайм. Весь чат — серый. Интенсивность — `--heat-*`.
5. **Паритет звучит по-разному.** Если стороны примерно равны, у каждой карточки своя фраза (раздел 5.3). Одна и та же фраза «примерно поровну» больше нигде не повторяется.
6. **Мало данных — карточки нет.** Каждая карточка имеет порог показа. Ниже порога она не показывается вовсе (никаких «Недостаточно данных» внутри), а отсутствующие вещи перечисляются одной строкой в конце части.
7. **Меньше текста.** Пояснение (серая строка под заголовком) — только если без него непонятно, что посчитано. Не больше 90 знаков.

### 3.1 Одна шкала для всех карточек **[новое, по аудиту прототипа]**

Аудит прототипа нашёл 13 стилей текста, 10 «сырых» кеглей (эмодзи 20–40 px, слово 56–96 px) и около 20 разных отступов. В отчёте остаётся только это:

| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Текст          | `--text-title` вопрос · `--text-h2` ответ и значения · `--text-figure` одно главное число (72 → 56 на телефоне) · `--text-small` подписи и значения у полосок · `--text-caption` оси и легенды. `--text-ui` — только чипы и кнопки |
| Отступы        | 4 внутри полоски · 8 внутри блока · 16 между блоками карточки · поля карточки 24 / 20                                                                                                                                              |
| Выравнивание   | всё по левому краю; по правому — только значение собеседника в конце полоски                                                                                                                                                       |
| Радиусы        | карточка `lg` · плашка внутри `md` · чипы и полоски `full` · метки графиков 3 px                                                                                                                                                   |
| Эмодзи, иконки | один размер эмодзи `--emoji-size` (28, новый токен) · иконки 16 / 20 / 24                                                                                                                                                          |

`--text-figure`, `--text-figure-sm`, `--text-h3`, `--text-label`, `--text-lede` в карточках отчёта не используются.

**При переносе в приложение (по аудиту четырьмя агентами, 06.11):**

- Табличные цифры: шорткат `font:` сбрасывает `font-variant-numeric`, поэтому `.t-num` из `base.css` перебивается scoped-стилями. Нужно одно правило на корне отчёта с селектором выше классов (в прототипе `#report *`).
- `tokens.css`: `--text-figure` на телефоне сейчас 48 — нужно 56. `--text-h2` на телефоне 22/28 — так и оставить, шкала «24 → 22».
- Тёмная тема: `--tile-grey` поднять до `#202024` (grey-плитка сейчас сливается с `--surface`). Новый токен `--chart-peak` (светлая `--heat-1`, тёмная `#2b3420`) — подложка пика в «Ваше время».
- Аватар «вы» — `--you` на `--surface`. На лаймовой плитке оба аватара на `--on-lime-well`.
- Имена классов: состояние «главный» у графиков — `.is-peak`, а не `.top` (конфликт со sticky-шапкой).
- Числа и единицы не разрываются: неразрывный пробел в форматтерах («38 кружочков», «у Милы 4,1»), окна времени — `white-space: nowrap`.
- Касания на телефоне не меньше 44 px: кнопка «назад», «Поделиться», сегменты, play, крестик диалога.
- Исключения из «всё по левому краю»: значения фактов на телефоне (список «название — значение»), даты на концах оси графика, числа над ступенями пьедестала. Полоска сравнения — одна для всех: «значение ━━━ ━━ значение» (`.line`).

## 5. Правила сравнений (useVersus)

### 5.1 Кто ведёт

- Отношение `ratio = больше / меньше`. **Паритет** — `ratio < 1,25` (для долей — 45–55%).
- `1,25 ≤ ratio < 10` — «в 1,6 раза чаще».
- Одна сторона = 0 — «только вы» / «только Мила».
- Сумма событий < 5 — карточки нет (кроме «Кто отвечает быстрее»: нужна медиана у обеих сторон).

### 5.2 Фраза-ответ, когда кто-то ведёт

### 5.4 Картинка при паритете

- **Смехометр** **[новое]**: на 12 часах всегда стоит засечка баланса (`--text-muted`, 2 px, 10 px длиной за дугой) с подписью «поровну» над ней (`--text-caption`).
