# Опись и шкалы «Портрета» v3 (09.11.2026)

Работа шла по `../POLISH-PROMPT.md` на макетах и в дизайн-системе. Сайт устарел (решение владельца), поэтому его значения брались только для справки: его обошли скриптом на 360, 390, 820 и 1440 px в обеих темах, по 10 экранов на каждую ширину.

## Было → стало (разных значений на всех досках макетов)

| Категория                   | Было | Стало | Что ушло                                                                                   |
| --------------------------- | ---- | ----- | ------------------------------------------------------------------------------------------ |
| Скругления                  | 10   | 8     | 2 и 3 px: полоски пульса и ручка листа стали пилюлями, клетки календаря и квадраты — 4     |
| Аватары                     | 5    | 4     | 48 → 40 (меню отчёта, первый вход)                                                         |
| Высоты контролов            | 7    | 5     | 32 → 36: одна компактная высота; ответ угадайки 64 → строка 56                             |
| Иконки                      | 7    | 6     | 18 → 20, 22 → 24; остались 16 / 20 / 24, плюс знак и кольцо прогресса                      |
| Кегли                       | 20   | 17    | 36, 40, 52 и 96 из inline-стилей → роли display / figure                                   |
| Стили текста                | 44   | 36    | inline-кегли, имя на мини-постере 16/22 → 16/24, факты «Итогов» → h2                       |

| Тени и линии                | 16   | 15    | линии 0,5 / 1,5 → 1 px, кольца выбора и фокуса — 2 px, тень миниатюр убрана                |
| «Сырые» значения в разметке | 35   | 0     | всё через токены: `--safe-bottom`, `--fab-clearance`, `--page-max`, `--inspector`, `--row` |

Оставшиеся «нешкальные» значения — это фиксированные исключения:

- кегль инициалов в аватаре = 0.4 × диаметр;
- имя на постере — плавающий display: зависит от ширины, до трёх строк;
- клавиатура устройства;
- безопасная зона снизу 34;
- миниатюры кадров — уменьшенная копия кадра.

## Шкалы и роли

- **Пространство:** 2, 4, 8, 12, 16, 24, 32, 40, 48, 64 — у каждого шага своя роль:

  | Шаг     | Роль                                                   |
  | ------- | ------------------------------------------------------ |
  | 2       | волосяной зазор                                        |
  | 4       | внутри контрола                                        |
  | 8       | связанные элементы                                     |
  | 12      | между карточками на телефоне                           |
  | 16      | поля телефона, отступ карточки, между карточками на ПК |
  | 24      | отступ карточки на ПК                                  |
  | 32      | разделы, поля планшета                                 |
  | 40      | поля и разделы ПК                                      |
  | 48 / 64 | воздух экранов входа и лендинга                        |

  Шаг 80 удалён. Внутри группы зазор всегда меньше, чем между группами.

- **Типографика — 9 ролей:**

  | Роль    | Кегль/интерлиньяж (телефон / ПК) | Начертание |
  | ------- | -------------------------------- | ---------- |
  | caption | 12/16                            | 500        |
  | small   | 14/20                            | 400 / 500  |
  | ui      | 15/20                            | 500        |
  | body    | 16/24                            | 400 / 500  |
  | h3      | 20 / 22                          | 600        |
  | h2      | 24 / 28                          | 600        |
  | h1      | 30 / 34                          | 600        |
  | figure  | 44 / 56                          | 600        |
  | display | 56 → 88, плавающий               | 600        |

  Это на одну роль больше гипотезы промта. ui 15 оставлен для кнопок, фильтров и меню — это subheadline из HIG: кнопки на 16 стоят тесно в строках. Числа сравнения сторон — кегль h2 с начертанием 500.

- **Размеры:**
  - контролы — 44 (всё, что нажимают на телефоне, и поля), 36 (компактные: строки, фильтры, ПК);
  - 56 — не кнопки: шапка, строка, клетки кода;
  - иконки — 16 / 20 / 24;
  - аватары — 24 / 32 / 40 / 64.
- **Форма:**
  - скругления 4 / 8 / 12 / 16 / 20 (на ПК 24) / 32 и пилюля; вложенные углы концентричны;
  - линия — 1 px, кольцо выбора и фокуса — 2 px;
  - тени — `--shadow-float` (плавающая кнопка, капсула) и `--shadow-overlay` (меню, лист, окно); плитки плоские.
- **Нейтрали:**
  - чернила #1D1D1F (Apple), вторичный текст #6C6C72, фон #F2F2F7;
  - линия #E5E5EA, линия контрола #D1D1D6;
  - в тёмной теме: #F5F5F7 / #98989D / #38383A / #48484A.
- **Цвета людей — одна лестница OKLCH.** Было: светлота постеров 0.78–0.89, лаймовый на 0.11 «громче» лавандового. Стало:

  | Роль           | Светлота L |
  | -------------- | ---------- |
  | постер         | 0.82–0.85  |
  | оттенок        | 0.92       |
  | метка          | 0.62       |
  | имя            | 0.52       |
  | тон на постере | 0.41       |
  | комната        | 0.977      |

  Каждая семья берёт самую светлую ступень в пределах допуска 0.03, на которой сохраняет насыщенность: лайм и мята — 0.85, лавандовый и голубой — 0.82. Коралловый 09.11 заменён жёлтым — единственным на 0.88: ниже жёлтый становится горчичным. Контраст:
  - метка на белом — ≥ 3.4:1;
  - имя — ≥ 5.2:1;
  - тон на постере — ≥ 5.1:1;
  - чернила на постере — ≥ 9:1.

  Картинка «было / стало» — `../sheets/ladder-compare.png`.

- **Движение:**
  - нажатие 90 мс;
  - смена состояния 150 мс;
  - лист и окно 400 мс на пружине, уход за 150 мс по кривой M3 exit;
  - анимируются только transform и opacity.

## Сквозная цельность: что выровнено между экранами

- **Главы отчёта.**
  - Первая находка каждой главы стоит крупно и без карточки («Кто пишет больше», «Ваше время»).
  - «Слово переписки» — единственная плитка цвета постера.
  - Лид главы не повторяет ответ первой карточки: «Баланс почти идеальный — и в словах, и в скорости».
- **«Ваши рекорды» на ПК** — строка из трёх фактов на всю ширину вместо колонки с пустотой под ней. Календарь — на всю ширину.
- **Высоты и иконки** одинаковые на всех экранах: компактные кнопки в строках 36 везде, иконки в кнопках, строках и меню — 20.
- **Справка о сайте (не меняется в этом раунде):** в нём 351 токен, из них 13 не используются нигде. Кегли сайта отличаются от макетов (h2 20/22, figure 52/64). Всё это уходит при переносе макетов в код.
