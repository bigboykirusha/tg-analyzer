Оценку делали так, как требует процесс `critique` из скилла Impeccable: две изолированные проверки, которые не видели выводов друг друга, и их сведение.

- **B — замеры.** Детектор Impeccable в браузере на 20 комбинациях «экран × тема × устройство», статистика вычисленных стилей, аудит исходников по Web Interface Guidelines от Vercel.

- **D — движение и взаимодействия.** Разобрал все анимации и взаимодействия по скиллам `emil-design-eng` и `apple-design`.

## 1. Общая оценка версии «Зеркало» (до этого редизайна)

**25 из 40 по эвристикам Нильсена: «приемлемо».** Оценки по пунктам:

| Пункт                       | Оценка |
| --------------------------- | ------ |
| Видимость состояния         | 2      |
| Соответствие реальному миру | 3      |
| Контроль                    | 3      |
| Согласованность             | 2      |
| Предотвращение ошибок       | 3      |
| Узнавание                   | 2      |
| Гибкость                    | 2      |
| Минимализм                  | 2      |
| Восстановление после ошибок | 3      |
| Помощь                      | 3      |

Ревьюер признал три сильные идеи, которые принадлежат именно этому продукту:

- зеркальный пульс переписки («вы» сверху, собеседник снизу);
- правило «ink — вы, цвет — собеседник»;
- карточка, отвечающая одной фразой.

Всё остальное читалось как добротный шаблон. Причина — сразу несколько примет сгенерированного дизайна из `frontend-design`:

- кремовый фон `#f4f3ef` с контрастными засечками;
- почти чёрный фон с кислотным лаймом;
- карточки внутри карточек;
- строки через «·»;
- серая «акцентная» половина заголовка;
- главы «01/02/03» без последовательности;
- иконки-«искорки»;
- наклонённое 3D-окно браузера на лендинге.

## 2. Десять главных проблем

1. **P0. Один факт — два ответа.** Отчёт писал «Вечерние собеседники» при пике в 11–14, «Итоги» — «Дневной ритм». Голосовые: «поровну» в отчёте и «Мила» в сторис. Серия «208 дней подряд» дублировала календарь «208 из 208».
2. **P1. Цвет собеседника почти не виден.** Лайм на белом — 1.50:1 при норме 3:1. Нижняя ступень тепловой карты — 1.09:1: чат, где писали каждый день, выглядел пустым.
3. **P1. Нет иерархии.** Около 25 одинаковых полосок, 9 из 11 ответов «Вы двое» — «поровну».
4. **P1. Групповой отчёт — стоковый дашборд.** «Победитель» с перевесом в один процент, «Ядро» у каждого участника, графики без ответов.
5. **P1. Обещание приватности не там, где решается доверие.** На шаге телефона его нет. «Удалить всё» спрятано в диалоге выхода.
6. **Блики тёмной темы.** Самое яркое на вечернем экране телефона — лаймовая плита.
7. **Верх отчёта показывает число, а не находку.** Одинокая глава «Ровно», пустые середины плиток.
8. **Заголовки экранов в разных местах.** На главной — h1 44 px на y≈120, в остальных экранах — 24 px засечками у края шапки.
9. **Шаблонный шум.** Около 20 строк через «·», «искорки», нумерация, декоративные иконки рекордов.
10. **Движение.**
    - Reduced motion выключал всё, вплоть до индикатора загрузки.
    - Кольцо фокуса плавно проявлялось на каждый Tab.
    - Бегунок и полоски анимировали `left` и `width`.
    - Смена темы показывала половину страницы светлой.

## 3. Два направления и выбор

|                   | A «Ясность»                                                                    | B «Портрет»                                                                            |
| ----------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| Идея              | грамматика Health и Screen Time, нейтральные карточки, индиго против мандарина | у каждого человека свой цвет; отчёт открывается его постером; страница — его «комната» |
| Сильное           | читаемость чисел, доверие                                                      | эмоция, «вы против него» без легенды, отличимость                                      |
| Слабое            | клон Health, Inter — шрифт по умолчанию                                        | дороже во внедрении                                                                    |
| Итог (взвешенный) | 35.25                                                                          | **39.5**                                                                               |

**Выбрано B, с дисциплиной A.** Экраны управления (главная, список, аккаунт, вход, FAQ) остаются спокойными и нейтральными. Цвет появляется только там, где есть человек: в его отчёте, «Итогах», аватаре и полосках. Действия монохромны, поэтому цвет означает только человека (HIG: «не используйте один цвет для разных значений»).

## 4. Что сделано («Портрет»)

- **Палитра.** Нейтральные серые в духе сгруппированных фонов HIG. Тёмная тема — настоящий чёрный фон и приподнятые ступени.
- **Цвета людей.** Семь оттенков, все в OKLCH с одинаковой светлотой. У каждого есть:
  - постер (белый текст ≥ 6:1, приглушённая строка 4.6:1);
  - метка (≥ 4.6:1 на белом);
  - «комната», колодец и «подсветка» для аватара;
  - тёмные пары всех ступеней.
- **Шрифт.** Одна гарнитура — Onest (кириллица в первую очередь, переменная), лестница кеглей по образцу Apple. Начертания 400/500/600, межстрочные на сетке 4.
- **Отчёт.**
  - Постер: имя крупно, «4 800 сообщений с 14 апреля», зеркальный пульс, главы — только когда их три и больше.
  - Шапка над постером принимает его цвет, а имя прячет только визуально: h1 остаётся для экранных дикторов. Когда постер уходит вверх, шапка становится стеклом с именем — «большой заголовок» из HIG.
  - Карточка: тихий вопрос → ответ (h2, 600) → сноска → картинка.
  - Части без номеров.
  - «Рекорды» и «Номинации» группы — сетки с волосяными линиями вместо карточек в карточках.
- **Согласованность метрик.**
  - Время суток для отчёта и «Итогов» берётся из одного `lib/persona.ts`.
  - «Поровну» везде считается одним `isEven` (перевес меньше 1.25×).
  - Серия во всю историю не повторяет календарь.
  - Лидер группы показывается только при явном перевесе.
- **Доверие.**
  - Обещание о приватности под главной кнопкой лендинга и под полем телефона.
  - Отдельная строка «Удалить все отчёты и выйти» в аккаунте.
  - FAQ — один лист обещаний вместо шести карточек с иконками.
- **Лендинг.** Заголовок одним голосом; вместо 3D-окна браузера — постер примера.
- **Главная.**
  - Приветствие крупным заголовком.
  - Плитки «Главного» с аватаром и цветом человека.
  - Месяц — полосками в цветах чатов.
- **Движение.**
  - Reduced motion оставляет короткие затухания, индикатор загрузки продолжает вращаться.
  - Фокус появляется мгновенно.
  - Бегунок и полоски двигаются через `transform`, с пружиной Apple в `linear()`.
  - Нажатие срабатывает за 90 мс, у карточек сжатие слабее (0.985).
  - Смена темы — в одном кадре.
  - `:active` работает на iOS.
- **Детектор Impeccable.**
  - Изначально: на ПК — 0 анти-паттернов на всех экранах кабинета в обеих темах.
  - После правок: `/`, `/faq`, `/login`, `/example` — 0 находок (был контраст на постере 3.4:1 и «висячие» слова).

## 5. Telegram и Spotify: что взято и почему

- **Telegram, цвет человека.** Взято по исходникам iOS-клиента (`AvatarNode.swift`): цвет = `abs(peerId) % 7` из семи семей (красный, оранжевый, фиолетовый, зелёный, бирюзовый, синий, розовый). Человек носит у нас ту же цветовую семью, что и в Telegram, только в нашей приглушённой палитре. Для «зеркала» переписки это узнавание (HIG: Familiarity).
- **Telegram, аватар.** Мягкий вертикальный градиент: основа сверху, светлее снизу.
- **Telegram, меню строки чата.** Открывается правым кликом или долгим нажатием.
- **Spotify.** Интерфейс ахроматичен, а цвет приходит от содержимого. У Spotify его даёт обложка, у нас — человек. Постер переходит в «комнату», и шапка держит его цвет до прокрутки.
- **Не взято:** кислотные градиенты и плотные «дашбордные» экраны Spotify, Liquid-эффекты, прямое копирование вида Telegram.

## 6. Что осталось

1. **Ещё не сделанные сигнатурные моменты движения** (отчёт D):
   - однократное раскрытие отчёта;
   - рост полоски «вы против него» от центра;
   - открытие «Итогов» как продолжение превью;
   - перетаскиваемый лист «Поделиться» на телефоне с передачей скорости пальца.
2. **Групповой отчёт как «состав и разговор»** (кто начинает, кто кому отвечает) вместо набора метрик. «Ядро» у всех участников.
3. **Мелкие пункты Web Interface Guidelines:**
   - поиск и фильтр `/new` в URL;
   - подтверждение и отмена отключения ссылки и угадайки;
   - Intl-формат часов;
   - «Настройки» в меню аватара — ссылкой;
   - кольцо фокуса у кадра «Итогов».
4. **`useMasonry`** читает и пишет раскладку вперемешку: стоит сгруппировать чтения.
