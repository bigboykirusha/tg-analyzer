# 0008 — целостность Telegram-сессий и задач анализа

Миграция добавляет сохранённые параметры постановки задачи, одну Telegram-сессию и одну активную задачу на пользователя, уникальный BullMQ id, а также индексы истории, восстановления задач и очистки refresh-сессий.

Перед изменением схемы preflight останавливает миграцию при дублях Telegram-сессий, активных задач или BullMQ id. Записи не удаляются и не выбираются автоматически: оператор должен изучить их, завершить лишние задачи или сессии и повторить миграцию.

Откат приведён в [`0008-down.sql`](0008-down.sql). Перед откатом нужно остановить API и worker: старая версия приложения не сохраняет параметры постановки и не обеспечивает уникальность активной задачи.
