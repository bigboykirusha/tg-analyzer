# Карта кода

Где что лежит — чтобы менять интерфейс, не читая весь репозиторий. Срез на 11.11.2026 (main, 6b6e965 и позже).

## Поиск по коду

- **Graphify** (MCP, репозиторий `bigboykirusha/tg-analyzer`, индекс обновляется после пуша): хорошо видит TypeScript — API, аналитику, композаблы. `graphify_impact`, `graphify_callers`, `graphify_trace` отвечают «кто вызывает» и «что заденет правка». **Vue-шаблоны с автоимпортом Nuxt он почти не видит** (`<UiButton>` в шаблоне — не ребро графа): для «где используется компонент» — `grep -rl "<UiButton" apps/web/app`.
- Пример: `deriveReportMetrics` (`packages/shared/src/analytics/derived.ts`) вызывают API отчёта (`apps/api/src/modules/reports/repository.ts → getReport`), публичная ссылка (`share/repository.ts → publicReport`) и пример (`apps/web/app/lib/example-report.ts`); сам он собирает `activity`, `habits`, `favourites`, `insights`, `quiz`, `words`.

## Данные

- `packages/shared/src/analytics/*` — вся аналитика отчёта, чистые функции с тестами; `significance.ts` — пороги, когда блок показывать.
- `packages/shared/src/api/*` — контракт API (zod).
- `apps/api/src/modules/*` — `auth` (вход, сессии), `parse` (разбор, очередь), `reports`, `share`, `account`, `system` (ошибки, алерты), `notify` (уведомления и бот); `telegram/` — шлюз teleproto (форк GramJS) и демо-шлюз `fake-gateway.ts`.
