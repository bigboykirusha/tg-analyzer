## Поиск по коду

- **Graphify** (MCP, репозиторий `bigboykirusha/tg-analyzer`, индекс обновляется после пуша; в сессии десктопного приложения подключается через настройки MCP — без него хватает `grep` и этой карты): хорошо видит TypeScript — API, аналитику, композаблы. `graphify_impact`, `graphify_callers`, `graphify_trace` отвечают «кто вызывает» и «что заденет правка». **Vue-шаблоны с автоимпортом Nuxt он почти не видит** (`<UiButton>` в шаблоне — не ребро графа): для «где используется компонент» — `grep -rl "<UiButton" apps/web/app`.
- Пример: `deriveReportMetrics` (`packages/shared/src/analytics/derived.ts`) вызывают API отчёта (`apps/api/src/modules/reports/repository.ts → getReport`), публичная ссылка (`share/repository.ts → publicReport`) и пример (`apps/web/app/lib/example-report.ts`); сам он собирает `activity`, `habits`, `favourites`, `insights`, `quiz`, `words`.

## Состояния, которые надо помнить при любой правке

- **Загрузка:** скелетоны главной (`reportsHint`), списка чатов, отчёта (`ReportSkeleton`), стартовый кадр `spa-loading-template.html`.
- **Пусто / ошибка / нет сети:** `UiEmptyState`, `StatusPage` (`/offline`, `error.vue`), отказ загрузить отчёты/чаты.
- **Новичок:** `HomeFirstRun`; первый отчёт открывается сам.
- **Разбор:** подключение → ожидание Telegram (`waiting`) → чтение → «Собираем отчёт» → готово (лист 6 с «Открыть», плитка) / ошибка / отмена / мало сообщений / лимит в сутки / очередь.
- **Сеансы:** вход истёк (refresh refused), сеанс Telegram отозван (`telegramSessionActive=false` → «Войти снова»), вход по кнопке бота, инкогнито.
- **Бот:** не настроен (строк нет), не подключён («Подключить»), подключён («Приходят и в Telegram»).
- **Отчёт:** личный / группа / гость / пример; есть новые сообщения (кольцо); обновляется; блоки без данных скрыты (пороги в `packages/shared`).
- **Темы и ширины:** светлая/тёмная; 360–430, 640, 900, 1200, 1440; установленное приложение (safe area, полоса «домой»).
