# Дизайн-система TG Analyzer

Короткие правила, по которым собран интерфейс. Значения живут в коде, здесь — только смысл и ссылки. Это единственный источник правил дизайна. `docs/design/README.md` и доски — история редизайна 31.10–03.11.2026.

## Основа

- **Токены** — `apps/web/app/assets/styles/tokens.css`. Компоненты используют только их: новый оттенок, размер или трекинг — это новый токен со значением для каждой темы. `color-mix()` и цвета в компонентах запрещены.
- **Тёмная тема** описана один раз в `:root[data-theme='dark']`. Тему до первой отрисовки ставит скрипт в `<head>` (`nuxt.config.ts`).
- **Глобальные классы** — `assets/styles/base.css`: шкала текста `.t-*`, плитки `.tile*`, сетки `.report-grid` / `.report-columns`, поле `.input`, строка-заметка `.note`, `.spinner`, `.skip-link`.
- **UI-кит** — `components/ui`, вызывается с префиксом `Ui…`. Иконки — только из `lib/icons.ts` (Lucide).

## Цвет

- `--text`, `--text-muted`, `--text-subtle` — текст; `--surface` — карточка, `--surface-2` — заливка внутри карточки, `--bg` — страница.
- **Действие — графит** (`--accent`). Primary-кнопка одна на экран.
- **В данных у цвета одно значение на весь продукт:**
  - ink (`--you`) — **вы**, и ничего другого;
  - лайм (`--them`) — **собеседник** или «остальные» в группе;
  - серый (`--chart-neutral`, `--chart-neutral-strong` для пика) — **весь чат**, обе стороны вместе (объём, недельный ритм, части суток);
  - шкала `--heat-1…4` — **интенсивность** (тепловая карта, окно на часах, самый активный день недели).
- **Плитки** (`tone` у `ReportSection` или `.tile--ink | --lime | --grey`) задают роль карточки, а не сторону:
  - ink — главное и записи;
  - lime — ответ и собеседник;
  - grey — тихая справка;
  - белая — всё остальное.

  Две плитки одного тона не соседствуют, окрашено не больше трети карточек. Внутри плитки только её токены (`--on-*`). В тёмной теме ink-плитка светлая.

## Текст и цифры

- **Одна шкала:**

  | Класс      | Где                   |
  | ---------- | --------------------- |
  | `.t-h1`    | экран (в `UiPageBar`) |
  | `.t-h2`    | карточка, диалог      |
  | `.t-h3`    | секция                |
  | `.t-title` | строка, плитка        |
  | `.t-lede`  | лид                   |

  Свои размеры заголовков в компонентах не задаём.

- **Цифры** — табличные (`.t-num`), моноширинного шрифта нет.
- **Большие цифры:**
  - `--text-figure` — ответ карточки (число или короткое слово: «3 мин», «Поровну»);
  - `--text-h2` — ответ-фраза;
  - `--text-figure-lg` — только верх отчёта: «52 / 48» и «Слово вашей переписки».
- **Трекинг** — `--tracking-display / figure / h2 / h3 / title`, чем крупнее кегль, тем плотнее. Сырые `em` в компонентах не пишем.

## Форма и ритм

- **Радиусы** — шесть ступеней `--radius-xs…xl` + `full`. Полоски-пропорции — `--bar-height`, радиус pill.
- **Колонка страницы** — `--page-max` и `--page-gutter`. Ритм — `--page-top / gap / bottom`, `--card-padding`, `--card-gap`.
- **Брейкпоинты:**

  | Ширина      | Что меняется                                            |
  | ----------- | ------------------------------------------------------- |
  | 640         | телефон                                                 |
  | 900 / 901   | одна или две колонки, боковая панель                    |
  | 1024        | только гаттер                                           |
  | 1200        | шапки и сетка отчётов                                   |
  | 1100 / 1600 | только окно Mac на лендинге                             |
  | 340         | аварийные правила для экранов уже поддерживаемых 360 px |

  Других значений не заводим.

- **Касание** — компактная кнопка (36 px) на тач-экране ловит касание не меньше `--hit-min` (44 px) через `.btn::after`. Вид не меняется.

## Движение

- **Длительности** — `--duration-fast / normal / slow / sheet / chart / spin`, кривые `--ease-standard` и `--ease-drawer`.
- **Hover** — только в `@media (hover: hover) and (pointer: fine)`.
- `prefers-reduced-motion` обнуляет длительности и задержки (`base.css`).

## Композиция

- **Оболочки:**
  - публичные страницы — `layouts/default.vue` (`SiteHeader` + страница + `SiteFooter`);
  - кабинет — `layouts/workspace.vue` (`AppSidebar` на ПК, `AppHeader`).

  В обеих первой стоит ссылка «К содержимому».

- **Заголовок экрана** — `UiPageBar` в общей шапке, один h1. На главной до 900 px вместо имени стоит логотип, на ПК имя видно.
- **Страница** — `UiPageContainer` → `.page` → `UiPageSection`. Вход и статус-страницы — одна карточка по центру. На телефоне без карточки поля берут цвет карточки (`--surface-2: var(--surface)`), чтобы не слиться со страницей.

## Правила, общие для всех экранов

1. **Один факт — один дом.** Величина живёт в одной карточке, остальные места её не повторяют. Отчёт и «Итоги» дают один ответ. Окно «обычно на связи» везде берётся из `derived.availabilityProfile.peakWindow`.
2. **«Вы» всегда первым и слева** — в каждом сравнении, полоске, шкале и подписи «Вы · N Имя · M».
3. **Карточка «Кто …»** (`components/report/duel`): заголовок → ответ одним размером → своя картинка → строка с обеими сторонами. Картинки у карточек разные, грамматика одна.
4. **Строка = одно действие.** Строка с отчётом открывает его и подсвечивается при наведении. Строка без отчёта не подсвечивается, действие — кнопка, а в «Чарте месяца» — вся строка («+ Разобрать чат»).
5. **Один вход в каждую вещь.** Чат на главной встречается один раз. Аккаунт — внизу боковой панели и аватар на телефоне.
6. **Без баннеров.** Сообщение — строкой (`.note`) рядом с тем, к чему относится. Ошибка загрузки — `UiEmptyState tone="danger"` с «Повторить» в той же оболочке, не тост и не экран новичка.
7. **Нижний слой на телефоне один:** `UiBottomSheet` (меню) и `UiModalDialog` (подтверждения) — плавающий лист с отступом 8 px и скруглёнными углами. Два действия стоят в ряд, три и больше — стопкой.
8. **Загрузка** — скелет повторяет раскладку готового экрана. Крутилка — только `.spinner`.

## Проверка перед сдачей

Скриншоты 1440×900 и 390×844 (`isMobile`) в обеих темах. На 360–430 px нет горизонтального скролла. Длинное имя чата (80+ символов) не ломает строку, шапку отчёта и легенду графика.
