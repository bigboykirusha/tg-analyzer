# Замер визуального словаря

Скрипт проходит 11 экранов демо-стенда (`TELEGRAM_MODE=fake`) и считает то, что реально отрисовано: виды кнопок, формы поверхностей, текстовые стили, радиусы, отступы.

```bash
pnpm --filter @tg-analyzer/web measure http://127.0.0.1:3000 ./out desktop   # или mobile
pnpm --filter @tg-analyzer/web measure:summary ./out --check                 # сводка и проверка порогов
```

`measure` принимает адрес стенда, каталог для `audit-<режим>.json` и режим (`desktop` 1440×900 или `mobile` 390×844). Нужен поднятый стек и Chromium Playwright.

## Пороги (`summarize.mjs --check`, код выхода 1 при превышении)

| Что                                                          | Порог |
| ------------------------------------------------------------ | ----- |
| Видов кнопок (заливка, обводка, цвет текста, форма)          | ≤ 4   |
| Высот кнопок (размеров)                                      | ≤ 2   |
| Текстовых стилей (кегль / интерлиньяж / начертание) на экран | ≤ 8   |
| Текстовых стилей (то же) во всей системе, по всем экранам    | ≤ 8   |
| Радиусов в системе                                           | ≤ 5   |

Четвёртый вид (с 11.11) — значок без заливки (`UiIconButton plain`): «⋯» на плитке отчёта, в чернилах постера, и язык с темой в шапке публичных страниц; «назад», «закрыть», «поделиться» в шапках, листах и окнах — в круге с заливкой (третий вид). Новых видов сверх этих четырёх не заводим. Форма — по роли: у кнопки скруглённый прямоугольник 12, у значка, чипа и фильтра — круг/капсула; замер считает их одной системной формой, любое другое скругление — отдельный вид. Радиусов пять: метка 8 (столбики графиков), контрол 12 (кнопки, поля), карточка 16, лист 24, капсула.

Код страны перед номером телефона (`.select__addon`) нарисован как часть поля — флаг, код и стрелка текстом, без заливки — и считается полем, а не видом кнопки. Вордмарк «TG Analyzer» рядом со знаком (`.brand-wordmark`) — часть логотипа, картинка, и в текстовые стили не входит. Других исключений нет.

`--check` считает виды по тому, что отрисовано (вычисленные стили), а не по именам классов: семейство классов (`btn--primary`, `icon-btn`…) в сводке выводится только для сведения. Для каждого превышения сводка печатает перечень видов или стилей.

Строки списков, ссылки боковой панели, пункты меню и чипы данных в «кнопки» не входят. Часть экранов (отчёт, главная, «Поделиться») держит свои разнобойные стили в компонентах, которые переписывают другие группы; пока они не переписаны, порог по ним красный: это и есть замер прогресса.

Правила Stylelint (`pnpm lint`) отдельно запрещают кегли, радиусы и цвета вне токенов.
