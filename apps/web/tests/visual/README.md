# Замер визуального словаря

Скрипт проходит 11 экранов демо-стенда (`TELEGRAM_MODE=fake`) и считает то, что реально отрисовано: виды кнопок, формы поверхностей, текстовые стили, радиусы, отступы.

```bash
pnpm --filter @tg-analyzer/web measure http://127.0.0.1:3000 ./out desktop   # или mobile
pnpm --filter @tg-analyzer/web measure:summary ./out --check                 # сводка и проверка порогов
```

`measure` принимает адрес стенда, каталог для `audit-<режим>.json` и режим (`desktop` 1440×900 или `mobile` 390×844). Нужен поднятый стек и Chromium Playwright.

## Пороги (`summarize.mjs --check`, код выхода 1 при превышении)

| Что                                                          | Порог |
| ------------------------------------------------------------ | ----- |
| Видов кнопок (заливка, обводка, цвет текста, форма)          | ≤ 5   |
| Высот кнопок (размеров)                                      | ≤ 2   |
| Текстовых стилей (кегль / интерлиньяж / начертание) на экран | ≤ 8   |
| Текстовых стилей (то же) во всей системе, по всем экранам    | ≤ 8   |
| Радиусов в системе                                           | ≤ 5   |

Пять видов (с 13.11, направление «Лист»), все — капсулы: чернила (`primary`, одно главное действие), контур чернилами (`secondary`, отдельное второе действие), тихая серая заливка без контура (`quiet`, действие внутри строки списка: «Разобрать», «Подключить»), значок без подложки (`UiIconButton`: колокольчик, «назад», «закрыть») и полупрозрачная фишка над постером (те же secondary и значок на цвете человека). Новых видов сверх этих пяти не заводим. Радиусов пять: метка 8 (столбики графиков), колодец 12 (поля, строки меню), карточка 24, лист 32, капсула (кнопки, чипы, аватары).

Код страны перед номером телефона (`.select__addon`) нарисован как часть поля — флаг, код и стрелка текстом, без заливки — и считается полем, а не видом кнопки. Вордмарк «TGDuet» рядом со знаком (`.brand-wordmark`) — часть логотипа, картинка, и в текстовые стили не входит. Заголовок лендинга (`.landing__title`) на телефоне — роль display, подогнанная под ширину (`--display-fit`, две строки до 360 px): замер считает его стилем display в полный размер (`--display-max`), а не отдельным. Имя на постере отчёта (`.poster__name`) — та же роль display, подогнанная под самое длинное слово имени (не меньше h1), чтобы «Продуктовая команда» переносилась по словам. Других исключений нет. Замер входит в CI (джоб e2e).

`--check` считает виды по тому, что отрисовано (вычисленные стили), а не по именам классов: семейство классов (`btn--primary`, `icon-btn`…) в сводке выводится только для сведения. Для каждого превышения сводка печатает перечень видов или стилей.

Строки списков, ссылки боковой панели, пункты меню, чипы данных и круги людей в ленте «Разобрать ещё» (аватар с именем — объект списка, как строка) в «кнопки» не входят. Часть экранов (отчёт, главная, «Поделиться») держит свои разнобойные стили в компонентах, которые переписывают другие группы; пока они не переписаны, порог по ним красный: это и есть замер прогресса.

Правила Stylelint (`pnpm lint`) отдельно запрещают кегли, радиусы и цвета вне токенов.
